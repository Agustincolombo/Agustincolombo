## 🧑‍💻 About Me

I'm a freelance developer and CS student based in Córdoba, Argentina. I design and build full-stack web systems for local businesses — from inventory and financial modules to WhatsApp automation and fiscal integrations.

- 🔭 Currently building a **comprehensive workshop management system** on GCP with Next.js, n8n & WhatsApp bot integration
- 🎓 Studying Computer Science while freelancing full-time
- 🤖 Heavy user of **Claude Code** and local LLMs (Ollama + Open WebUI) for AI-assisted development
